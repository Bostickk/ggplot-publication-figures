# 临床效应与时间结局图

## 森林图

读取已确认的效应量表或模型结果，保持估计量、置信区间、参照组和调整状态。RR、OR、HR 使用比值尺度，通常采用对数横轴，零效应参考线为 1；均值差、风险差等加性估计的参考线为 0，按其单位绘制。每一行的名称、估计和区间一致，区间超出画布时调整画布或明确端点标记。需要展示参考水平时标记为 Reference。

默认采用清晰的黑色点线、简洁坐标和可读的数值列。分组颜色用于解释类别，避免无含义的逐行彩色装饰。示例 07 使用直接声明的模拟 RR 与 CI 表，绘图不拟合回归。

## Kaplan–Meier 生存曲线

曲线按事件时点阶梯变化，显示删失标记、说明区间类型，配套风险人数表。按现有定义标注随访起点和时间单位。提供了模型比较结果时照实标注，单纯绘图请求不自动增加 log-rank 检验或 Cox 模型。示例 08 使用模拟的单一事件随访数据，绘制 KM 和 log-log 95% CI。

## 累积发生率

有竞争事件的累积发生率使用提供的 CIF/Aalen–Johansen 结果，保持目标事件与竞争事件的编码、定义及估计方法。按估计对象清楚写出累积发生率和事件名称。风险人数表的时间点与曲线一致，说明人数的口径。示例 09 显式模拟目标事件、竞争死亡和删失，再在独立分析步骤计算 Aalen–Johansen 概率。

风险人数优先读取已提供的计算结果。仅有 CIF 概率和区间而缺少人数时，向用户索取对应时间点人数，或用于计算人数的随访数据。常规风险表使用指定时点前仍处于初始无事件状态且处于随访中的人数，明确目标事件、竞争死亡及删失的处理；Fine–Gray 模型的风险集另行说明，遵循提供的分析结果。

KM 和 CIF 分别回答生存概率与指定事件的累积发生概率，各自使用对应结果。分组用颜色和实线/虚线共同标识；删失短线按其语义显示，不套用分组原始观测的圆点样式。

## 后续图形的使用

比例图保留分子、分母和所用区间方法。相关性图标注实际系数类型及单位，带宽沿用提供的模型。一致性图按提供的差值定义与一致性界限绘制。ROC、校准、决策曲线从已确认的预测及验证结果读取。它们尚未进入本批可运行示例，不在 README 中宣传为已验证的模板。

样式实现：`../scripts/biomedical_styles.R` 的 `theme_biomedical("clinical")`。见 [临床示例](../examples/biomedical_gallery.md#07-forest)。

参考：[survival::survfit](https://stat.ethz.ch/R-manual/R-devel/library/survival/html/survfit.formula.html)、[survival 官方方法文档](https://cran.r-project.org/web/packages/survival/vignettes/survival.pdf)。
